Connect Slack so June can post IT notifications, start a thread for each request IT needs to see, and help people without leaving Slack.

## What June does in Slack

- **Notifications.** June posts alerts and updates to the notifications channel you pick.
- **Request threads.** When a request needs IT or an approval, June starts a thread for it in the notifications channel. The employee's messages and screenshots show up there, and IT can @June in the thread to work on the request.
- **Approvals.** June sends approval requests to approvers in Slack. When an approver rejects one, June asks them why and passes the reason on to the employee.
- **Help for June users.** People with a June account, usually your IT team, can DM June or @June in the channels you pick to get IT work done.
- **Help for employees.** Employees can DM June or @June in the channels you pick for their own IT help, such as software access, more AI usage, or a laptop problem.

## Before you start

- You can install apps in your Slack workspace, or a Slack admin can approve them for you.
- You are an admin in June.

## Step 1: Connect Slack

<Steps>
  <Step title="Start in June">
    1. Go to **Settings** > **Integrations**.
    2. Choose **Slack** and click **Connect**.
  </Step>

  <Step title="Approve June in Slack">
    1. Check that Slack shows the right workspace.
    2. Review the permissions June asks for. [Permissions](#permissions) explains what each one is for.
    3. Click **Allow**.

    <Note>
      If your workspace needs admin approval for new apps, Slack sends the request to a workspace admin. Once they approve it, click **Connect** in June again.
    </Note>
  </Step>

  <Step title="Come back to June">
    Slack sends you back to June, and the Slack integration shows as **Active**.
  </Step>
</Steps>

## Step 2: Pick the notifications channel

<Steps>
  <Step title="Add June to the channel">
    In Slack, open the channel you want June to post in and type `/invite @June`.
  </Step>

  <Step title="Pick it in June">
    On the Slack integration page, under **Slack Settings**, open **Notifications channel** and pick the channel.
  </Step>
</Steps>

## Step 3: Choose where June helps people

Under **Slack Settings**, **June users** and **Employees** each have two settings:

| Setting | What it does |
|---------|--------------|
| **Direct messages** | People can DM June. |
| **Channels** | Where people can @June. Choose **None**, pick the channels, or for employees, choose **Any channel June is in**. Everyone in a channel can see June's replies there. |

Both settings start off for both groups. Until you turn on direct messages or pick a channel, June doesn't take requests from that group in Slack. IT can always reply in a request thread in the notifications channel, whatever you choose here.

A few things to know:

- **Threads.** In a channel, June answers a message only when it tags June, replies in June's own thread included. June still reads the other replies, so it knows what was said.
- **People who are both.** If someone has a June account and is also an employee, June helps with their own IT needs as an employee, and with IT work for others as a June user.
- **Private details.** June helps in the channel, even with a password or a lockout. It moves to a DM only right before it would ask for or share a credential, like a password, a recovery key, or a license key. Credentials only ever go to the person who asked.

## Permissions

When you connect, Slack asks you to approve these permissions.

| Permission | Why June needs it |
|------------|-------------------|
| `app_mentions:read` | See when someone tags June. |
| `chat:write` | Post notifications, replies, and approval requests. |
| `channels:history` | Read the threads June is part of in public channels, so it can follow the conversation. |
| `groups:history` | Read the threads June is part of in private channels. |
| `im:history` | Read the DMs people send June. |
| `mpim:history` | Read group DMs that include June. |
| `metadata.message:read` | Recognize June's own messages in a conversation. |
| `im:read` | See basic details about June's DMs. |
| `im:write` | Start a DM with someone, for example to send a credential only to them. |
| `mpim:read` | See basic details about group DMs that include June. |
| `channels:read` | List public channels for the channel pickers. |
| `groups:read` | List the private channels June is in. |
| `channels:join` | Join a public channel when IT asks June to manage it. |
| `channels:write.invites` | Add people to a channel when IT asks June to. |
| `channels:manage` | Archive public channels, remove people from them, or change their topic when IT asks June to. |
| `groups:write` | Do the same for private channels June is in. |
| `users:read` | Look up people's names and profiles. |
| `users:read.email` | Match people in Slack to people in June by their work email. |
| `files:read` | Read the screenshots people send, so June can see the problem. |
| `files:write` | Copy an employee's screenshots into the request thread for IT. |
| `commands` | Run June's slash commands, such as `/june-access`. |
| `reactions:write` | Add emoji reactions to messages. |
| `assistant:write` | Use Slack's agent features: the status June shows while it works, suggested prompts, and conversation titles. |

### When June needs new permissions

Some June updates need a permission your Slack connection doesn't have yet. When that happens, the Slack integration page shows **Reconnect Slack to turn on the latest June features in Slack**. Click **Reconnect** and approve the permissions in the same workspace. Your settings stay the same.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Notifications don't show up">
    - Check that a notifications channel is picked under **Slack Settings**.
    - Make sure June is in that channel. In Slack, type `/invite @June` in the channel.
    - Check that the integration shows as **Active**. If it doesn't, click **Reconnect**.
  </Accordion>

  <Accordion title="June doesn't answer someone">
    - Check that **Direct messages** or **Channels** is turned on for their group, **June users** or **Employees**.
    - For a channel, check that it's picked, or that **Any channel June is in** is chosen for employees, and that June is in the channel.
    - June matches people by email. The person's Slack email has to match the email June has for them.
  </Accordion>

  <Accordion title="June says where it works instead of helping">
    The person asked June somewhere that isn't turned on for their group. June tells them where it does work, or points June users to the June web app. To help them where they asked, turn on direct messages or add the channel.
  </Accordion>

  <Accordion title="The app install is waiting for approval">
    Your workspace needs an admin to approve new apps. Ask a Slack workspace admin to approve June, then click **Connect** in June again.
  </Accordion>

  <Accordion title="The integration shows as disconnected">
    Someone may have removed June from Slack or revoked its access. Click **Reconnect** on the Slack integration page.
  </Accordion>
</AccordionGroup>

## Security

- June stores the Slack access token encrypted.
- Credentials, like recovery keys, only go to the person who asked, in a DM.
- You can remove June from your Slack workspace at any time, and June loses access right away.
