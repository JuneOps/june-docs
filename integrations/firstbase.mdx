Connect your Firstbase environment with June to track equipment orders, returns, and inventory across your organization.

<Info>
The Firstbase integration is **read-only**. June reads your people, offices, warehouses, devices, orders and returns from Firstbase. It cannot create or modify records in Firstbase.
</Info>

## What you'll accomplish

- Generate an API key in Firstbase
- Configure the June integration
- Understand available data and actions
- Track equipment orders and returns

## Prerequisites

Before starting the integration, ensure you have:

- Firstbase admin access to generate an API key
- June organization admin permissions

## How June Works with Firstbase

### What June syncs

June syncs from Firstbase when you connect and then once a day:

- **People**, matched to your June employees by email. Firstbase people who don't match an employee are skipped.
- **Offices and warehouses**, added as June locations
- **Devices**: computers, phones, tablets and Apple TVs, with Firstbase's status, assignee, condition and, for purchased devices, price. Accessories are skipped.
- **Orders, returns and replacements**, with their status and the devices on them

### Available Actions

June answers from the Firstbase data it has synced. Looking up a Firstbase person's details is the one action that reads from Firstbase directly. All actions are read-only:

| Action | Description |
|--------|-------------|
| **Get order** | Retrieve order details including status, items, SKU info, and shipment tracking |
| **List orders** | List orders with filters for date range, person, serial number, and status (for example active or needs attention) |
| **Get orders by person** | Get all orders for a specific employee |
| **Get return** | Retrieve return details including status, retrieval method, and items |
| **List returns** | List returns with filters for date range, person, serial number, status, and replacement |
| **Get returns by person** | Get all returns for a specific employee |
| **Get employee** | Retrieve employee details from Firstbase (name, email, address, package) |
| **Search employees** | Search for employees by email, first name, or last name |
| **Get inventory by serial** | Look up Firstbase's record for a device by serial number |
| **Get inventory by person** | List the devices Firstbase reports as assigned to a person |

## Setup Process

### Step 1: Generate an API Key

<Steps>
  <Step title="Access Firstbase Settings">
    1. Log in to [Firstbase](https://app.firstbasehq.com)
    2. Navigate to **Settings** > **API** (or **Integrations**)
  </Step>
  
  <Step title="Create API Key">
    1. Click **Generate API Key**
    2. Enter a descriptive name: `june-integration`
    3. Click **Create** to generate the key
  </Step>
  
  <Step title="Copy and Save Key">
    1. **Immediately copy** the API key
    2. Store it securely for the next step
    
    <Warning>
    You won't be able to view the API key again after leaving this page. If you lose it, you'll need to generate a new one.
    </Warning>
  </Step>
</Steps>

### Step 2: Connect in June

<Steps>
  <Step title="Connect Firstbase in June">
    1. In June, go to **Settings** > **Integrations** and select **Firstbase** under **Available Integrations**
    2. Paste the key from Step 1 into **API Key** and click **Connect**
    3. June checks the key with Firstbase, shows the integration as **Connected**, and starts the first sync
  </Step>
  
  <Step title="Test the Connection">
    1. Open **Firstbase** under **Configured Integrations**
    2. Open the **Connected** menu and choose **Test Connection**. June checks the API key with Firstbase again.
    3. Resolve any authentication issues before proceeding
    
    <Check>
    Once the first sync finishes, try asking June "Show me recent Firstbase orders" to verify the integration is working.
    </Check>
  </Step>
</Steps>

## Troubleshooting

### Common Issues

<AccordionGroup>
  <Accordion title="Authentication failed - invalid or expired API key">
    **Symptoms**: Connection fails or shows authentication errors
    
    **Solutions**:
    - The API key may have been revoked in Firstbase
    - Generate a new API key in Firstbase settings
    - Update the API key in June's integration settings
    - Verify there are no extra spaces when pasting the key
  </Accordion>
  
  <Accordion title="Order, return or person not found">
    **Symptoms**: June says it has no Firstbase order or return with that ID, or that no employee is linked to a Firstbase person
    
    **Solutions**:
    - The record may not have synced yet. Run **Sync Now** from the **Connected** menu, or wait for the daily sync.
    - June keeps only orders and returns that include a computer, phone, tablet or Apple TV, so accessory-only orders don't appear
    - If no employee is linked, check that the person's email in Firstbase matches their employee record in June
  </Accordion>
  
  <Accordion title="Empty results when listing orders/returns">
    **Symptoms**: Queries return no results when you expect data
    
    **Solutions**:
    - Check the date range and status you asked for
    - Confirm the employee has orders or returns in Firstbase and that their email matches their June employee record
    - Check that the integration's last sync completed
    - Try broadening your search criteria
  </Accordion>
  
  <Accordion title="Connection timeout errors">
    **Symptoms**: Requests take too long and fail
    
    **Solutions**:
    - Firstbase API may be experiencing issues
    - Try again in a few minutes
    - Check Firstbase status page for outages
    - Contact June support if the issue persists
  </Accordion>
</AccordionGroup>

## Security Best Practices

### API Key Management

- **Dedicated Keys**: Use a dedicated API key for June so it can be revoked independently if needed
- **Secure Storage**: API keys are encrypted at rest in June's secure storage
- **Regular Rotation**: Consider rotating API keys periodically (quarterly recommended)
- **Access Auditing**: Review API access logs in Firstbase regularly

### Data Access

- **Read-Only Access**: The Firstbase integration only reads data. It cannot create or modify orders, returns or people in Firstbase.
- **What June reads**: People, offices and warehouses, devices, orders and returns
