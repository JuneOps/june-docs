The June browser extension measures how long your employees keep your tracked apps open and in focus in their browser. June shows that usage beside each person's app access, so you can see who really uses what.

It works in Google Chrome, Microsoft Edge and Brave. You deploy it to managed browsers, and employees can't remove it.

## What it tracks

The extension measures time in focus for apps on your Tracked Applications list, and nothing else.

- Time counts while a tracked app's tab is open and in focus.
- Time stops when the person switches tabs or leaves the browser window.
- Time does not pause when the person steps away from the computer.

It doesn't record browsing history, URLs, page titles, page content or keystrokes. For sites that aren't on your list, it stores and sends nothing. It reads only the domain name of the page.

### Choose which apps are tracked

Manage the list under **Settings** > **Browser Extension**.

- When you turn on the extension, June fills the list with your managed apps.
- Add, edit or remove apps and domains at any time.
- A domain also matches its `www.` version.
- Wildcards work, for example `*.slack.com`.

## What is sent to June

Each report contains:

- The date and your time zone
- For each tracked app: an app identifier, seconds in focus, and the last time it was in focus that day

Every request to June also includes:

- The browser profile email
- The device serial number, if the June Device Agent is installed
- The browser name
- Your organization's provisioning token

The extension tries to send data every 6 hours, and when a tracked app comes into focus. Only completed days are sent. If a device is offline, data waits on the device and is sent when it reconnects. Unsent data older than 30 days is discarded on the device.

If the extension can't identify the person, it doesn't report. This happens when there is no signed-in browser profile and no Device Agent.

## Where it shows in June

- **Apps:** apps the extension sees list **Browser extension** as a source.
- **Employee access:** each person's app access shows when they last used the app and their average daily time over the past 7 days.
- **New access records:** if someone uses a tracked app they had no access record for, June adds one. It is marked as found by the browser extension, not as a license.
- **Rollout status:** **Settings** > **Browser Extension** shows how many browsers have the extension installed and how many checked in within the last 24 hours.

## Deploy the extension

June hosts the extension itself. It isn't in the Chrome Web Store.

- Extension ID: `oogjlgdkbojpipjkjinhaeijjokhkkmd`
- Install method: force-install by policy
- Chrome: deploy with Google Admin Console
- Edge and Brave: deploy with your device management tool

Each organization has one provisioning token, set in the managed setting `provisioningToken`. If you regenerate the token, the old one stops working. Redeploy the extension with the new token.

The step-by-step guide is in June under **Settings** > **Browser Extension**.

## Permissions

The browser shows these permissions when the extension is installed.

<AccordionGroup>
  <Accordion title="Storage" icon="hard-drive">

  <Accordion title="Alarms" icon="clock">

  <Accordion title="Tabs" icon="window-restore">

  <Accordion title="Native Messaging" icon="message-dots">

  <Accordion title="Identity and user email" icon="envelope">

  </Accordion>

  <Accordion title="All URLs" icon="globe">
    Lets the extension check each page's domain against your list. Chrome describes this as being able to read and change data on all websites. The extension reads only the domain name and doesn't read or change page content.
  </Accordion>

  <Accordion title="Idle" icon="clock-rotate-left">
    The extension requests this permission but doesn't use it today.
  </Accordion>
</AccordionGroup>

## June Device Agent

The June Device Agent is a small native app for macOS and Windows. It gives the extension the device serial number. It runs locally and makes no network requests.

Deploy it with:

- Jamf Pro or Kandji on macOS
- Microsoft Intune on Windows

On Windows, add a Microsoft Defender exclusion so the agent can run. The setup guide in June shows the exact steps.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Does the extension track browsing history?">
    No. It records only time in focus for apps on your list. It doesn't record URLs, page titles, page content or keystrokes, and it stores nothing for other sites.
  </Accordion>

  <Accordion title="What happens when a device is offline?">
    Usage stays on the device and is sent when the device reconnects. Unsent data older than 30 days is discarded.
  </Accordion>

  <Accordion title="How often does it send data?">
    It tries every 6 hours, and when a tracked app comes into focus. Only completed days are sent, so today's usage appears in June after the day ends.
  </Accordion>

  <Accordion title="Which apps are tracked?">
    Only apps on the Tracked Applications list under **Settings** > **Browser Extension**.
  </Accordion>

  <Accordion title="Does it affect browser performance?">
    It does a quick domain check against your list. It doesn't scan or change page content.
  </Accordion>
</AccordionGroup>
