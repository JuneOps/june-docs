Use an import for devices that no connected tool knows about, such as a spreadsheet of older laptops or peripherals. Devices from tools like Jamf Pro and Kandji sync on their own.

Only Owners and Admins can import. The file must be a CSV with a header row, up to 10 MB.

## Import a file

<Steps>
  <Step title="Start the import">
    In June, go to **Settings** > **Import Data**, click **New Import**, and choose **Asset Import**.
  </Step>
  <Step title="Upload">
    Click **Click to upload a CSV file**, or drag the file onto the page.
  </Step>
  <Step title="Map columns">
    June lists each column from your file with a sample value. Check that each one points to the right field, and untick any you do not want. Required fields must be mapped. Click **Review Data**.
  </Step>
  <Step title="Review">
    June checks every row. If all rows are valid, you see how many are ready. Click **Import**.
  </Step>
  <Step title="Check the result">
    You see **Total Processed**, **Successfully Saved** and **Failed**. Click **View Assets** to open the inventory.
  </Step>
</Steps>

Nothing is saved until you click **Import**. Before then, **Cancel Import** discards the upload.

## Prepare your file

There is no template to download. This header row is the smallest file that works:

```csv
Serial Number,Asset Product Name
```

June maps a column on its own only when the header matches the field name exactly, including capitals. Any other header still imports, but you map it by hand in the Map Columns step.

| Header | What it does |
| --- | --- |
| Serial Number | Identifies the asset. A row without one adds no asset. |
| Asset Product Name | Required. Adds the product to your catalog if the name is new. |
| Email | Assigns the asset to that person, and creates them if they are new. |
| Department Name | Sets the department. Creates it if it is new. |
| Location Name | Sets the location. The location must already exist, with the same name. |

Other columns are optional. You can include Manufacturer, Model and SKU for the product, and Asset Condition, Asset Category, Asset Status and Ownership Type for the device. For purchase details, use Asset Purchase Date, Asset Cost, Vendor, PO Number and Asset Warranty Expiration. The Map Columns step lists every field you can use.

Some values to plan around:

- **Asset Category:** computer, mobile_device, tablet, apple_tv, monitor, keyboard, mouse, dock, headset, headphones, peripheral_other or other. Capitals do not matter, and a value June does not recognize becomes other.
- **Asset Condition:** new, good, needs_repair, broken or unknown.
- **Asset Cost:** a plain number such as 2499.00. Leave out currency symbols and commas.
- **Dates:** use YYYY-MM-DD.

## How rows are matched

| Item | Matched by |
| --- | --- |
| Asset | Serial Number. A serial number June already has updates that asset, including devices synced from your device tool. |
| Product | Asset Product Name |
| Person | Email |
| Department | Department Name |
| Location | Location Name |

On an asset that already exists, a blank cell leaves the current value alone. To clear a value, put the word NULL in the cell.

### Assignment and status

When a row has an email, June assigns the asset to that person. When it has a location and no email, June assigns it to the location. June then sets the asset's status to match, as described in [Asset status](/assets/asset-status). A status you import, such as IN_REPAIR, is kept.

If a connected device tool manages the device, June sends the new assignment to that tool first. If the tool does not know the device, the asset becomes **Awaiting Enrollment**.

## If something looks wrong

| What you see | Why and what to do |
| --- | --- |
| **Validation Failed** with an Invalid Records table | One bad row blocks the whole import. The table shows the row number, its data and the problem. Fix the CSV and click **Upload New File**. |
| **Asset: Product is required but not provided** | The row has no Asset Product Name. Add a product name to every row. |
| An email error | The Email value is not a valid address. |
| **Failed** is above zero after Import | Usually a Location Name that does not match an existing location. Create it first under **Locations**, then import those rows again. The other rows were saved. |
| Columns were not mapped automatically | The headers differ from the field names. Pick the field yourself in Map Columns, or rename the headers and upload again. |
| Costs import as zero or the wrong amount | The cost contains a currency symbol or a comma. Use a plain number. |

## FAQ

<AccordionGroup>
  <Accordion title="Can I upload an Excel file?">
    No. Save the sheet as CSV first.
  </Accordion>
  <Accordion title="Can I import the same file twice?">
    Yes. Rows match on Serial Number, so a second import updates the same assets instead of adding copies.
  </Accordion>
  <Accordion title="Can I import departments, locations or products on their own?">
    Yes. **New Import** also offers **Department Import**, **Location Import** and **Product Import**. They use the same steps.
  </Accordion>
</AccordionGroup>
